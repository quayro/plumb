# Repository conventions

Generated by `plumb instructions` from the effective policy (`plumb.json`, preset `ozmikhail`). Change the policy, not this text.

## Workflow

- Before editing a file, run `plumb inspect --file PATH` and follow the conventions it lists.
- After editing, run `plumb check`. Exit 0 is the only pass; exit 2 means a check could not run, which is a failure to fix and never a result to work around.
- `plumb fix` repairs formatting and generated regions. `plumb explain RULE` gives a rule's purpose and remedy.
- Never edit the policy, an exception, an API snapshot or a protected file to make a check pass; those change only by review.

## Projects

- `.` is a typescript project.
- `packages/python` is a python project.
- `packages/sdk` is a python project.
- `packages/sdk` is a rust project.

## Files

- Required: `AGENTS.md`, `README.md`, `bun.lock`, `docs/index.md`, `plumb.schema.json`.
- Never add files matching `**/*.mjs`, `**/*.js`, `**/*.cjs`.
- `src/**/*.ts`, `bin/**/*.ts`, `scripts/**/*.ts`, `test/**/*.ts`, `packages/**/*.ts` are named `^[a-z][a-z0-9-]*(?:\.test)?\.ts$`: runtime and tests are erasable TypeScript modules with consistent names
- `docs/**/*.md` are named `^[a-z0-9][a-z0-9-]*\.md$`: documentation pages use kebab-case names

## Protected files

- Change `src/**`, `bin/**`, `scripts/**`, `packages/javascript/**`, `packages/python/**`, `plumb.schema.json`, `AGENTS.md` only with an owner's review.

## Commits

- One title-only Conventional Commit per change: `type(scope): subject`, lowercase subject, no trailing period.
- Scopes: `plumb`.
- At most 100 characters.
